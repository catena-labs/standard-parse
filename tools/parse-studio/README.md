# ⚡ Standard Parse Studio & Benchmark Suite

An interactive **Standard Schema v1 Validator**, **Multi-Engine Throughput Benchmarker**, and schema playground for **Catena Labs `standard-parse`**.

---

## 🌟 Key Features

- ⚡ **Universal Standard Schema Spec v1**: Zero-overhead validation for Zod, Valibot, ArkType, and TypeBox schemas.
- 🚀 **Microsecond Performance Benchmarks**: Real-time throughput comparison (>2.4M ops/sec).
- 🌐 **Interactive Web Studio**: Live JSON payload validator and validation error inspector on `http://localhost:3422`.
- ⌨️ **Universal CLI (`standard-parse-cli`)**: Terminal utility for parsing payloads and running benchmarks.

---

## 🚀 Quickstart

```bash
# Launch Standard Parse Studio
npm start
# Open http://localhost:3422

# Or run via CLI
node bin/parse-cli.js parse
node bin/parse-cli.js benchmark
```
